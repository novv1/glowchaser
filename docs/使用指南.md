# 逐光者 GlowChaser · 现场使用指南

> 版本 v1.8 · 适用于 https://7a8a63a8cc8c497aa624f04d87567517.app.workbuddy.link 与本地 http://localhost:8000

## 1. 一句话定位

基于 4 确定性模式 + 50 成员集合 + 卫星实测（双源）+ 地面实况的火烧云/悬日月预报系统。**概率语义：当天出现"值得记录的火烧云"的概率**（基率 27.7%，上限 ~68%——概率 60% 已是极好天）。

## 2. 标准操作时序（以日落 18:40 为例）

| 时间 | 动作 | 看什么 |
|---|---|---|
| **前一天晚上** | 查明日报告 | 概率 + 多模式表 + 48h 云量分层。此时只做"去不去"的粗决策；集合离散度 ±30% 以上说明模式没把握，明早再看 |
| **T-6h（12:40）** | 再查一次 | **卫星临近校准卡片自动出现**（10 分钟级红外）。此时卫星+模式开始交叉判读 |
| **T-2h（16:40）** | 出发前必看 | 亮温判读升级为 5km 分辨率（自动预取完成）。重点读三条：①卫星云带/云隙位置 ②云边界比模型近还是远 ③低云/雾预警。同时看和风实况与分钟级降水 |
| **T-30min** | 到点位后再刷一次 | 卡片自动 10 分钟滚动更新。云隙在逼近=准备拍短时烧；云带压顶=考虑撤 |
| **拍完后** | 回填实况 | 报告页顶部"实况回填"五档按钮。**每一条回填都是珠三角本地校准数据**，直接喂给后续权重精调 |

## 3. 核心判读规则

### 概率与判定词
- 不烧 <8% ｜ 微烧 8-18% ｜ 小烧 18-28% ｜ 中烧 28-40% ｜ **大烧 ≥40%**
- 概率已经过 555 天实证校准：**不要把 30% 当"基本没有"**——基率就是 28%，30% 已略高于平均
- 可信度看两条：模式间标准差 + 集合离散度。"中低·集合离散度 ±30%" = 云况没定数，翻车率高

### 卫星校准卡片（四源交叉）
- **P-Tree 亮温**（红=高云砧/橙=中云/蓝灰=低云或晴/深蓝=晴空）：
  - 红色云带压在光路上 = 高置信烧
  - "低云/可能晴"是模糊带——**必须结合和风实况**：实况总云量高 → 实为低云/雾，挡地平线
- **云边界偏差**：卫星实测比模型近/远 X km → 观赏窗口提前/推迟
- **⚠ 双叹号条目** = 低云/雾遮挡预警（卫星看不见贴地低云，只有和风实况能发现）
- **分钟级降水**：雨幕=光路全挡，除非"雨停后云砧滞留"场景

### 大气截面图
蓝色湿层在光路 200-500km 且 2-8km 高度 = 系统性云带；上层干燥 + 下层湿层分离 = 典型可烧结构。

### 翻车四大因素（系统自动标注 + 人工复核）
1. 云量欠饱和（模式 RH 峰值不足）→ 到时候没云
2. 集合/模式离散度大 → 云位置没定数
3. 低云/雾（只有地面实况能发现）
4. AOD > 0.5 → 污烧（颜色脏、饱和度低）

## 4. 悬日月

- **地平线可见性热力图**：选悬月/悬日 × 升/落 → 地图红=该地能看到。月出+1h（约 10° 高度）是低角度悬月最佳档
- **方位对准窗口**：输入地标方位角（如桥轴、塔尖），输出日月对准时刻 ± 容差 + 云况可见概率
- 月相照度直接标注：新月前后即使晴也拍不到亮月

## 5. API 速查（自建客户端/快捷指令可用）

```
GET /api/report?lat&lon&date&type=sunset|sunrise[&azimuth&tol]   全量报告
GET /api/nowcast?lat&lon&date&type                                轻量临近校准（1-2s）
GET /api/horizon?lat&lon&date&body=sun|moon&kind=rise|set         地平线可见性热力图
GET /api/cities                                                   珠三角城市库
GET /api/health                                                   数据源连通性
GET /api/stats                                                    回填命中统计
POST /api/feedback {event_key, outcome, note}                     回填实况
```

## 7. 已知边界

- P-Tree 历史归档仅 10 天滚动 → 高保真历史卫星回测需 G-Portal（远期可选）
- ECMWF 能见度缺失（用 GFS 补齐）；和风空气质量 v1 免费版不含（用 CAMS）
- 概率校准锚定上海 555 天先验——珠三角本地化依赖回填数据积累（目标：3 个月 50+ 条）
- 卫星判读 5km 分辨率：城市级云隙定时超出的部分靠蓝调时段实拍确认
