事件时刻
    读图方法
    • 横轴：从观测点沿日落/日出方向的光路城市，按距离排序
    • 纵轴：高度（km），850~200hPa 位势换算
    • 蓝色深浅：高层相对湿度 —— 越蓝越湿，越可能成云
    • 灰幕下沿为地影线：线下方的云已进入地球阴影、不再被太阳照亮 （线随滑块时刻下沉，即"低云先黑、高云续烧"）
    • 青色虚线为 0°C 层：该高度以上云顶温度已在冰点以下（冰晶主导， 反光更亮；线不出现 = 整层冰点以上）
    • 光路西侧高湿层 + 云带 → 最可能烧成火烧云
    • 拖动时间滑块：观看 T-6h ~ T+1h 光路湿度剖面的演变
    MONITOR C · 探空● LIVE

    温度探空 · 露点廓线 ECMWF 气压层 5 层 + 地面 · 事件时刻

    读图方法
    • 橙线=气温 T，蓝虚线=露点 Td；两线贴近（T−Td ≤ 2°C）= 该层接近饱和， 成的云更"实"、不易出幡状拖尾
    • 青色竖线 = 0°C 层：其上云顶温度在冰点以下（冰晶主导，反光更亮）
    • 这是模式 5 层粗廓线（+地面 2m），用于量级判断；逐层精确探空需 radiosonde 对账（待接）
